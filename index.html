What is a .xavatar file?

A ZIP archive containing avatar.png, picture.png, eight DXT5 DDS images, and online.json. Designed for compatible custom-avatar tools on jailbroken PlayStation consoles; this page does not install avatars or modify your console.

Animated images use the first frame. Formats depend on ImageMagick support; unsupported or damaged files show an error. The conversion engine loads locally with the page.
