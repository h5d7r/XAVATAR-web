    What is a .xavatar file?

    A ZIP archive containing avatar.png, picture.png, eight DXT5 DDS images, and online.json. this page does not install avatars or modify your console.

    Animated images use the first frame. Formats depend on ImageMagick support; unsupported or damaged files show an error. The conversion engine loads locally with the page.

    How to Apply the Avatar?

    Once you have generated your .xavatar file, transfer it to your console via FTP or USB. You can apply it using one of the following methods:

    Method 1: PSX-Xplorer

    1. Navigate to the file location using PS4-Xplorer 2.0 (or PS5-Xplorer).
    2. Simply press the button on the .xavatar file to apply it.
    3. Press + to apply it.

    Method 2: Avatar Changer App

    1. Move the .xavatar file to the following path on your console: /data/AVATARS/
    2. Open Avatar Changer (or Avatar Changer PS5).
    3. Select and apply the image from within the application.
